作者验证

使用 Albert 的 GitHub 发布凭证。只有拥有本站仓库写入权限的人才能发布。

首次使用，如何获取凭证？

在 GitHub 的 Settings → Developer settings → Personal access tokens → Fine-grained tokens 中创建令牌。Resource owner 选择 albertyizhan，仅授权 tgyizhan.github.io 仓库，Repository permissions 中将 Contents 设为 Read and write，并设置较短有效期。不要把令牌写进文章或发给别人。
